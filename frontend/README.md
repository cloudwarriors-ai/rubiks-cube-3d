# Frontend - Rubik's Cube 3D

React + TypeScript + Three.js frontend for the Rubik's Cube 3D simulator.

## Setup

```bash
npm install
npm run dev
```

## Note

The complete frontend source code is available in the original build at:
`/root/code/rubic-cube-demo/demo-1-1191920251137/frontend/`

This repository contains the backend implementation and documentation.
For the full application, please refer to the original build location.
